# 🎮 Blox-Velha! — Jogo da Velha Interativo

Projeto web responsivo desenvolvido como aplicação prática de lógica de programação, estruturas de decisão e desenvolvimento front-end.

### 🚀 Funcionalidades e Tecnologias
- **Linguagens & Estilização:** HTML5, CSS3 (Tailwind CSS) e JavaScript (ES6+).
- **Inteligência Artificial:** Três níveis de dificuldade, incluindo algoritmo **Minimax** para tomadas de decisão ótimas.
- **Áudio Dinâmico:** Efeitos sonoros sintetizados em tempo real via **Tone.js**.
- **Persistência de Dados & PWA:** Salvamento automático de pontuação, ranking e patentes via `localStorage`, além de suporte a Progressive Web App (`manifest.json`).
